While traditional software development relies on writing code line by line, advancing LLM (Large Language Models) and AI assistants are fundamentally changing this paradigm.

As an **AI-Assisted Developer**, I completely delegate the raw coding process to AI assistants in my projects, while focusing on product ideas, architectural design, user experience, and precise prompt management.

### 3 Core Steps of My AI Development Workflow

1. **Idea & Architecture Planning:** 
   Defining application features, Jetpack Compose UI layout, and service requirements like Firebase/AdMob.

2. **Precision Prompt Engineering:**
   Providing project context, data flows, and Kotlin/Android standards to advanced models like Gemini and Claude using precise instructions.

3. **Iterative Build & Verification:**
   Transferring generated code to Android Studio, analyzing build errors and logic gaps with AI, and resolving them iteratively.

Through this approach, I have successfully launched multiple Android applications such as AstroYorum, NotesAssistant, OptiDoc, and ValutaRate from scratch. When combined with developer vision, AI dramatically accelerates the transformation of ideas into real-world products.
