## Project Overview

**OptiDoc** is a privacy-conscious Android utility designed to shrink the file footprint of scanned documents, photos, and PDF files without degrading visual readability. All operations execute strictly on-device, safeguarding sensitive enterprise and personal paperwork.

### Architecture & Technical Design

- **On-Device Compression:** Zero network calls for file processing; all compression algorithms leverage client-side hardware processing.
- **Intelligent Downsampling:** Strips obsolete metadata while selectively recompressing embedded raster images to preserve crisp typography.
- **Modern Kotlin Stack:** Android Jetpack components, Kotlin Coroutines for asynchronous file streaming, and strict Scoped Storage support.

### Key Capabilities

1. **PDF Compression:** Rapidly optimizes oversized PDF documents to easily clear email and messenger attachment thresholds.
2. **Batch File Processing:** Enqueue multiple documents simultaneously for background execution.
3. **Guaranteed Privacy:** 100% offline assurance for confidential legal, academic, and financial documents.
