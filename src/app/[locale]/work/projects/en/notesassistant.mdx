## Project Overview

**NotesAssistant** is a distraction-free Android companion crafted to capture spontaneous thoughts, research notes, and action checklists with clarity and structure.

### Architecture & Technical Design

- **Hardware-Backed Encryption:** AES-256 local database encryption backed by the Android Keystore system and biometric biometric fingerprint authorization.
- **Responsive Text Engine:** Instant markdown rendering engine enabling fluid editing of lists, tables, and code snippets.
- **Fast Full-Text Search:** High-performance indexing across notes, custom tags, and body copy.

### Key Capabilities

1. **Tagging & Hierarchical Organization:** Flexible color tagging and smart folder filters to organize thoughts intuitively.
2. **Comprehensive Markdown Support:** Headings, checklists, code blocks, and blockquotes with instant visual previews.
3. **Frictionless Export:** Share formatted notes seamlessly via PDF, Markdown, or raw text.
