## Project Nucleus

Project Nucleus brings your everyday desktop tools, productivity utilities, and system monitoring into a single floating, modular panel on Linux.

### Key Features
- **Modular Card Architecture**: Responsive, draggable grid of cards you can customize, reorder, and configure.
- **Lightweight & Blazing Fast**: Built on Tauri and Rust for native performance with minimal memory overhead.
- **Glassmorphic Aesthetic**: Clean, modern frosted glass UI toggled with a single global shortcut or tray icon.
