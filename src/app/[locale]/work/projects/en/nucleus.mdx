## Project Overview

**Project Nucleus** is a next-generation desktop system manager and control center tailored for Linux environments. By pairing a high-performance, low-overhead Rust backend with a frosted glassmorphic web interface, it provides deep system observability and seamless hardware controls without burdening system memory.

### Architecture & Technical Design

- **Core Daemon (Rust):** Direct Linux kernel queries, hardware monitoring (CPU, RAM, temperatures, fan speeds), and process tracking with zero memory leaks.
- **Frontend Layer (TypeScript & Web):** Minimalist frosted glass aesthetics, CSS variables, and responsive micro-animations.
- **IPC Bridge:** Ultra-fast, secure local socket communication bridging system events to the visual user interface.

### Key Capabilities

1. **Real-Time Telemetry:** Live monitors for CPU load distributions, memory usage, storage, and network throughput.
2. **Quick System Actions:** One-click power profiles (performance / power saver), display parameters, and audio routing.
3. **Modular Widget System:** Extensible framework allowing users to design and plug in customized system widgets.
