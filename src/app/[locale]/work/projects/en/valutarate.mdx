## ValutaRate

ValutaRate tracks exchange rates and provides currency conversion capabilities for Android users.

### AI-Assisted Architecture

- **API Integration**: I directed the AI to implement API polling and parsing within the Kotlin environment.
- **State Management**: Managed the application state during data fetching via AI prompts.
- **UI/UX**: Delivered a readable interface utilizing modern Android UI components.
