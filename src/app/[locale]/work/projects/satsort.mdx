## Project Overview

**SatSort** is an open-source Linux desktop tool created to effortlessly parse, organize, and reorder proprietary `.sdx` binary satellite channel list files used by major smart TVs (including Vestel, Arçelik, Beko, and Grundig).

### Architecture & Technical Design

- **Binary Parser:** Reverse-engineered byte-level specification of the `.sdx` binary container, offering dependable parsing and validation.
- **Desktop UI (PySide6 / Qt6):** Native, snappy desktop interface built with modern Qt6 design principles.
- **Channel Engine:** Multi-select operations, drag-and-drop ordering, LCN (Logical Channel Numbering) re-indexing, and fast text filtering.

### Key Capabilities

1. **Intuitive Drag-and-Drop:** Rearrange hundreds of satellite and terrestrial channels in seconds.
2. **Favorites & Categories:** Create and manage customized channel bundles such as Sports, News, and Cinema.
3. **Automated Safety Backups:** Automatically snapshots original `.sdx` files prior to saving edits.
