## Curalis

Curalis is a privacy-first, local-first intelligent medication and personal health tracking application built for Android.

### Key Features
- **Smart Medication Reminders**: Dose tracking, inventory alerts, and flexible scheduling.
- **Privacy by Design**: 100% offline-first architecture using Room DB with zero unnecessary data collection.
- **Modern UI**: Designed with Jetpack Compose and Material 3 for a seamless, accessible user experience.
