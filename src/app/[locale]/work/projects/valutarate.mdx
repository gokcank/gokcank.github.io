## Project Overview

**ValutaRate** is a lightweight, responsive financial calculator and currency monitor that keeps users up to date with global exchange rates, cross parity calculations, and precious metals markets.

### Architecture & Technical Design

- **Offline Currency Cache:** Automatically stores the latest exchange rates in a local database so conversions and calculations function flawlessly during travel or connectivity loss.
- **Low-Latency Polling:** Reliable data synchronizations from international central banks and financial market APIs.
- **Minimalist Architecture:** Zero bloat, lightweight memory footprint, and energy-conscious background synchronization.

### Key Capabilities

1. **Multi-Currency Conversion:** Convert between multiple currencies concurrently on a unified interactive screen.
2. **Custom Portfolio Watchlist:** Pin essential currency pairs and configure price movement alerts.
3. **Historical Trend Charts:** 7-day, 30-day, and yearly parity movements mapped on high-performance vector graphs.
